# `localclaw setup`

Initialize `~/.localclaw/localclaw.json` and the agent workspace.

Related:

- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
localclaw setup
localclaw setup --workspace ~/.localclaw/workspace
```

To run the wizard via setup:

```bash
localclaw setup --wizard
```
